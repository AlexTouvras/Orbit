Field system 03 · Operating system

Turn evidence into a decision

Question → evidence → tension → narrative → experience → decision

Story is the controlled transformation of evidence into understanding. Start with the decision, not the dataset. Find the tension that makes the next scene necessary. Unfold understanding on purpose. Leave uncertainty visible. End on what changes operationally.

Craft still matters inside every stage: dwell, claim, sketch, lead, open. Chart type is a lane. A bar is honest when “larger” is the whole claim. A custom mark is earned when the conventional form cannot carry the idea. Grain stays on Analytics. Cutover stays on Delivery. Essays stay prose.

Field test: Can someone understand what changed, why it matters, and what remains uncertain?

Problem → use → example

A chart looking for a reason to exist Start with the question Audience, decision, question, context, scope, success — before any mark. No meaningful question → no story
The library chose the argument Interrogate evidence first Source → structure → signal → limits. Evidence constrains the story; the story never upgrades it into certainty
Interesting information, no next scene Find the tension Expectation → reality; aggregate → distribution; signal → mechanism. If nothing creates need, it is analysis, not a story
Scenes in random order Narrative spine Orient → question → signal → mechanism → consequence → decision → open. Segel & Heer: who leads, then who wanders
A custom mark that hides the comparison Claim → then form Magnitude → bar; change → slope; uncertainty → band. Break convention only when convention cannot express the idea
Animation because we can Experience with a job Static, progressive, scroll, explore, simulate, drill — only if it reduces uncertainty, reveals mechanism, or enables exploration
“Now you understand” and stop Close on decision Insight, implication, action, boundary, supporting evidence, and what could change the conclusion
Doubt buried in a footnote Open — keep doubt visible Cairo: truthful before beautiful. The miss and the window you refused belong in the picture

Craft inside every stage: dwell until someone is in the file → one sentence → a sketch that is not a library screenshot → the eye’s path → the doubt left visible. If the grain is wrong, use Analytics. If the release is the job, use Delivery.

Story spec (write this down)

Question + claim Decision-facing question; one sentence the story asserts.
Evidence + tension Source, grain, window — and the unresolved relationship.
Narrative + visual Scene order from orient to open; form chosen for the claim.
Interaction + implication What the reader can change, why; what could change operationally; visible limits.

Ladder + gates

  1. State the decision in one sentence
  2. Interrogate what the evidence can say
  3. Name the tension that needs the next scene
  4. Order scenes: orient → open
  5. Pick the form for the claim; give interaction a job
  6. Close on implication, boundary, and uncertainty
Kill switch If you cannot name the question, the tension, and what changes, it is a chart — not a story yet.

Kill the story when…

  • No question — a visualization looking for a reason
  • No tension — information with no unresolved relationship
  • Chart-first — the library chose the argument
  • Narrative laundering — causality on correlational evidence
  • Decoration as interaction — motion that does not change understanding
  • Certainty theatre — doubt only in a footnote
  • A gallery titled “story” — many charts, no decision
  • Wrong field — grain is Analytics; cutover is Delivery; essays stay prose
