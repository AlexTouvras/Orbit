The order of the reading

A reading order, not a dashboard

Ask → cast → show → move → close

A data story is a question a stranger can ask, answered before they have to explore. The question is the title. A few figures answer it before the picture. The picture is one scene: a map, a tape, or a mix. Moving it changes that same scene. The close names the source, the lag, and what the picture does not establish. Chart type, colour, and motion are lanes. A gallery that needs a tour is not a story. Essays stay prose. This order is for a live desk and for the front door. Grain, gold, and the semantic model stay on the Analytics card.

CASTThe figures that answer it, before the picture
SHOWOne picture: map, tape, or mix
MOVEThat same picture changes. No second page
CLOSESource, lag, and what this is not

Problem → use → example

If the real problem is… Use Example case
The title is the dataset Question as the title “Are Helsinki flats still rising in price?” The table name stays in the close
The number is under the map Figures before the picture Euro-area inflation, unemployment, and the deposit rate before the trend chart
Every chart type is in the deck One picture for the question Europe’s last-24h generation mix is one stacked comparison, not a gallery of fuel icons
The drill opens a second product Move the same picture Press a bidding zone. The price question stays. The zone desk is the same page
You need the animation to get the number Readable without motion The question, the figures, and the source still read when animation is off
No source, no lag, no limit Close the story Housing is Statistics Finland, CC BY 4.0, about a month late. It is not a listing site
Five equal cards and a tour One idea, then the next Delivery, then data, then AI — a sequence. Not a grid that asks the visitor to synthesise

Default order: name the question → put the answering figures first → one picture → interaction on that picture → source, lag, and the limit. If the grain is the problem, use the Analytics card. If the release is the problem, use the Delivery card.

What has to be written down

The question A stranger can ask it. The dataset name is not the title.
The cast Three to five figures answer the question before the picture.
The limit Source, lag, and what this picture does not establish. A human still makes the call.

Ladder + gates

  1. One question
  2. Figures that answer it
  3. One picture
  4. Move that picture
  5. Source, lag, limit
  6. Analytics if the grain is wrong — Delivery if the release is the job
Kill switch If you cannot name the question, the source, and what the picture does not establish, it is not a story yet.

Anti-patterns

  • Dataset name as the title
  • A chart gallery before the question
  • A second page for the default drill
  • Motion required to read the number
  • No source, no lag, no limit
  • A dark theme standing in for a story
  • Turning an essay into a scroll animation
  • Calling the grain a story — that’s the Analytics card
