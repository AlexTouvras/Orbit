A model earns its place one stage at a time

Nine stages turn a raw table into a monitored score. Each stage writes a file the next stage can refuse. A miss returns to an earlier stage. It does not spend the holdout twice.

Profile → Quality → Outliers → Features → Split → Train → Test → Serve → Monitor

The pipeline

01ProfileRoles, nulls, label rate
02QualityRepair, then re-profile
03OutliersPolicy, not silent drops
04FeaturesDecision-time only
05SplitFreeze test ids
06TrainTune inside train
07TestOne official read
08ServePrevious version stays
09MonitorNew version, not silent retrain

Miss loops

A · Tune

Inner slice of train only. Max 20 trials. Validation unread.

B · Features

Change the spec. Max 3 revisions. Then data.

C · Data

Named defect only. New split. Old test unread.

Stop

Blocked or rejected. Do not serve. Do not retune on test.
