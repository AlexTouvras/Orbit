## Overview

The Agentic Orchestrator coordinates a team of specialized LLM agents — a **planner**, a
**tool executor**, and an **evaluator** — to complete open-ended goals reliably. Instead of a
single prompt, work is decomposed into subtasks, executed with real tools, and graded before
results are returned.

## The problem

Single-shot LLM calls are brittle: they hallucinate, skip steps, and give no audit trail.
Teams needed a way to run multi-step AI workflows in production with **observability**,
**retries**, and **quality gates**.

## What I built

- A **planner agent** that decomposes goals into a typed task graph.
- A **tool executor** with sandboxed tool-use (search, retrieval, code, HTTP).
- An **evaluator** that scores groundedness and blocks low-quality outputs.
- Durable execution via Temporal so long runs survive restarts.

> Every run is fully traced: inputs, tool calls, token usage, and eval scores.

## Architecture

The control plane sits between the caller and the model/tool providers, mediating each step
and persisting state to Postgres + pgvector.

## Impact

- **94%** groundedness pass rate on the internal eval set.
- **8.2s** median run time for a 4-subtask plan.
- Cut manual review time by **60%** on the backlog-triage workflow.
