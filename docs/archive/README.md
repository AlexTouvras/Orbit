# Archive

Retired prose lives here so the current read order stays short.

Each file begins with `Archived from \`original/path.md\``. The old path, when something still links it, becomes a short pointer: `Superseded by` the owner named in `docs/ops/doc-registry.json`.

`npm run docs:check` fails when a pointer grows back into a second manual, when an archive file has no source line, or when a diagram file is missing from `docs/architecture/README.md`.
